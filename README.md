# Shop Restock Preview

A *Slime Rancher 2* mod that shows what a shop restocked right inside of the restock notification

**Download:** [Nexus Mods](https://www.nexusmods.com/slimerancher2/mods/208) or the [latest GitHub release](https://github.com/pyeight/ShopRestockPreview/releases/latest)

## Requirements
* *Slime Rancher 2* **1.3.0** (newer versions show a warning and may still work, older ones are not supported)
* [MelonLoader](https://github.com/LavaGang/MelonLoader.Installer/releases/latest)
* [Starlight](https://www.nexusmods.com/slimerancher2/mods/60) **4.0.4** or newer

## Installation
1. Install MelonLoader with the [MelonLoader Installer](https://github.com/LavaGang/MelonLoader.Installer/releases/latest).
2. Install [Starlight](https://www.nexusmods.com/slimerancher2/mods/60) 4.0.4 or newer.
3. Download Shop Restock Preview from [Nexus Mods](https://www.nexusmods.com/slimerancher2/mods/208) or the [latest GitHub release](https://github.com/pyeight/ShopRestockPreview/releases/latest).
4. Drop `Starlight.dll` and `ShopRestockPreview.dll` into your game's `Mods` folder.
5. Start the game.

## Settings
Found under `[ShopRestockPreview]` in `UserData/MelonPreferences.cfg`:

| Setting               | Default | What it does                                                                                            |
|-----------------------|---------|---------------------------------------------------------------------------------------------------------|
| `max_shown_items`     | `10`    | How many restocked items the notification shows. `0` turns the preview off.                             |
| `always_show_restock` | `true`  | Show the restock notification on every restock, even if you haven't opened the shop since the last one. |

## Update check
On startup the mod fetches `latestModVersion.txt` from this repository to tell you when a newer version is released.
